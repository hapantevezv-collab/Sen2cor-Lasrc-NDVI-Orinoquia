# Sen2cor-Lasrc-NDVI-Orinoquia
Versión final del artículo que cuantifica las diferencias NDVI entre TOA/L1C y reflectancia superficial procesada con Sen2Cor y LaSRC en paisajes silvopastoriles del Piedemonte Orinocense, integrando análisis estadístico, síntesis gráfica y documentación del plugin PyQGIS desarrollado.
